DRAG, DROP, DONE

Drop a single image or an entire folder and cmprssr queues everything automatically. Compress one file or a thousand — same workflow, same speed.

ONE QUALITY SLIDER

No presets, no profiles, no export menus. A single quality slider from 1–100 gives you full control. Set it once, compress everything, move on.
